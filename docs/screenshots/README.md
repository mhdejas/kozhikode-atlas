# App screenshots

These three PNGs are genuine browser viewport captures of the running Kozhikode Atlas. Each is 1265 × 649 pixels. They were copied without retouching, compositing, generated imagery, added labels or pixel edits. The election record was selected through the app's controls; the terrain was rotated, paused and scrolled into view using the existing interface. No candidate portrait was generated or replaced.

## Reference map

`reference-map.png` shows the district boundary, mapped places, connections and the reference legend. Its basemap attribution remains visible: Tiles © Esri, HERE, Garmin, OpenStreetMap contributors, GIS user community. These credits identify third-party map content, not a blanket MIT licence. The atlas's OpenStreetMap and boundary source terms remain applicable; see [data credits](../DATA_CREDITS.md).

## Terrain

`terrain-3d.png` shows the existing lightweight terrain renderer with elevation colours, location labels and controls. It is a rotated view, not north-up; relief is exaggerated 6×. The source/height limitations remain visible.

Terrain attribution: “produced using Copernicus WorldDEM-30 © DLR e.V. 2010-2014 and © Airbus Defence and Space GmbH 2014-2018 provided under COPERNICUS by the European Union and ESA; all rights reserved”. The Copernicus DEM public-use terms apply to the adapted terrain depiction; [source and licensing guidance](https://dataspace.copernicus.eu/explore-data/data-collections/copernicus-contributing-missions/collections-description/COP-DEM). The surface includes vegetation and buildings and is not a new ground survey.
